# Como baixar e acompanhar o projeto

## Baixar

Na pagina principal do repositorio, clique no botao Code e depois em Download ZIP. Extraia o arquivo em uma pasta do computador. O README da raiz explica a instalacao do Python e como iniciar a ferramenta.

O ZIP contem o programa e as telas. Nao contem bases da Receita, cadastros de usuarios, bancos privados, chaves de servicos ou o executavel do tunel. Para consultar empresas reais, configure a base local conforme as instrucoes do programa.

## Ver as atualizacoes

Atualize a pagina do repositorio para ver os arquivos enviados mais recentemente. O historico de commits mostra as alteracoes de cada versao. Mudancas ainda em preparacao nao aparecem no GitHub antes de um envio.

## Quem pode alterar o original

Um repositorio publico pode ser lido, baixado e copiado. Uma copia ou fork nao altera seu repositorio original. Para alterar o original, uma pessoa precisa de acesso de escrita ou de uma contribuicao aceita por quem administra o repositorio. Nenhum acesso de escrita a terceiros foi concedido nesta organizacao.

## O que fica guardado

O historico Git guarda as versoes do codigo que foram enviadas. Ele permite consultar e recuperar essas versoes. Nao e um backup dos cadastros e bancos da sua ferramenta, que ficam fora do repositorio; mantenha copias privadas desses dados separadamente.

## GitHub e a ferramenta funcionando

Disponibilizar os arquivos para download nao hospeda o sistema. Para usar a ferramenta, a pessoa precisa instalar as dependencias e executa-la em seu computador, com sua propria configuracao e base de dados. Nenhum tunel ou servidor publico foi iniciado como parte da organizacao deste repositorio.
